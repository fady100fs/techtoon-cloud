## 1. Overview

TECHTOON Accounting now has a dedicated multi-agent system within OpenCode. The **Techtoon Orchestrator** is the primary entry point that automatically delegates tasks to 11 specialist subagents.

## 2. How to Use

### Step 1: Select the Orchestrator

In OpenCode, select **"Techtoon Orchestrator"** as your primary agent (from the agent dropdown).

### Step 2: Send a Task

Write your task in natural language. The orchestrator will:
1. Analyze the request
2. Determine which specialists are needed
3. Delegate to them automatically
4. Collect and review results
5. Produce a unified report

### Step 3: Review Results

The orchestrator will present:
- Summary of what was done
- Which agents were invoked
- Changes made (files modified)
- Tests run (results)
- Conflicts detected (if any)
- Remaining issues
- Status: PASS / FAIL / NOT VERIFIED / BLOCKED

## 5. Safety Rules

The orchestrator enforces these safety rules for all agents:

1. No creating projects from scratch
2. No deleting functions/data without verification
3. No production DB changes without approval
4. No deployment without approval
5. No user/password changes
6. No mock/stub code for real functionality
7. No claiming PASS without evidence
8. No force push or destructive git operations
9. No hardcoded secrets
10. No auto-migration on production

## 6. Approval Gates

The orchestrator will **stop and ask for approval** before:
- Production database migration
- Production deployment
- User/password changes
- Destructive operations
- Architectural changes

## 7. Reporting

Every task produces a unified report with:
- **Summary**: What was done
- **Agents Invoked**: Which agents were used
- **Changes Made**: Files modified
- **Tests Run**: Test results
- **Conflicts**: Any disagreements
- **Remaining Issues**: What's left
- **Status**: PASS / FAIL / NOT VERIFIED / BLOCKED

## 8. Rollback

If anything goes wrong:
1. Delete `.opencode/agents/techtoon-*.md` files
2. Restart OpenCode
3. System falls back to global agents
4. No impact on project code or data

See `OPENCODE_AGENT_ROLLBACK_GUIDE.md` for details.
