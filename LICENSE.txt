Techtoon Accounting — Terms of Use / Licensing
==============================================

1) TRIAL
   Newly installed copies run in trial mode for 10 days starting from the first
   launch of this version. After the trial ends the program will not open until
   a valid license file (license.key) is placed next to the program executable.

2) LICENSE TYPES
   - lifetime  : permanent license (no expiry)
   - yearly    : 12 months from issue date
   - monthly   : 1 month from issue date
   - trial     : limited period (10 days by default)

3) LICENSE FILE
   The file "license.key" (JSON, digitally signed) must be placed in the same
   folder as the program executable. It is validated at every start.

4) MACHINE BINDING
   A license may be bound to one computer (machine id). To obtain your machine
   id run:
       Techtoon.LicenseTool.exe machine-id
   and send it to the vendor, or leave the machine id empty for an unmetered
   license.

5) DATA
   Your data stays on your own PostgreSQL/Neon database; the program does not
   send data anywhere else.
