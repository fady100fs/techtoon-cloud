## 2. Troubleshooting

### Issue: Agent not recognized
- **Cause**: File format incorrect or frontmatter invalid
- **Fix**: Check YAML frontmatter (name, description, mode, color)
- **Verify**: Agent file should match the format of existing global agents

### Issue: Subagent cannot be invoked
- **Cause**: Agent mode is `primary` instead of `subagent`
- **Fix**: Change `mode: primary` to `mode: subagent`
- **Note**: Only the orchestrator should be `primary`

### Issue: Agent returns empty/error response
- **Cause**: Agent prompt is too long or contains invalid characters
- **Fix**: Simplify the agent prompt, remove non-ASCII characters if needed

### Issue: Delegation depth exceeded
- **Cause**: Subagent trying to invoke another subagent
- **Fix**: This is by design — subagents cannot invoke other subagents. Only the orchestrator can delegate.
