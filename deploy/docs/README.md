# TECHTOON ACCOUNTING — دليل التوزيع والتشغيل

## 📦 محتويات الحزمة

```
deploy\distribution\
├── run_techtoon.bat          ← تشغيل البرنامج (نقرة مزدوجة)
├── check_license.bat         ← عرض حالة الترخيص
├── Application\              ← ملفات البرنامج (Techtoon.UI.exe — مستقل بالكامل)
├── Tools\
│   └── Techtoon.LicenseTool.exe   ← أداة إصدار التراخيص (للمورد)
├── Licenses\                 ← رخص موقّعة جاهزة (تجريبي / شهري / سنوي / مدى الحياة)
├── Documentation\            ← هذا الملف + دليل التثبيت
├── Logs\                     ← سجلات التشغيل (تُنشأ تلقائيًا)
├── Backups\                  ← النسخ الاحتياطية (تُنشأ تلقائيًا)
└── Manuals\                  ← أدلة المستخدم
```

## 🚀 التشغيل على أي جهاز Windows

### المتطلبات

| البند | المطلوب |
|-------|---------|
| نظام التشغيل | Windows 10 / 11 (64-bit) |
| معالج | Intel Core i3 أو أفضل |
| ذاكرة | 4 GB أو أكثر |
| مساحة | 250 MB للبرنامج + مساحة قاعدة البيانات |
| **.NET Runtime** | ❌ **غير مطلوب** — النسخة self-contained |
| قاعدة البيانات | PostgreSQL 12 أو أحدث |

### الخطوات

1. **انسخ مجلد `Application` كاملًا** إلى أي مكان على الجهاز
   (مثلًا `C:\Program Files\Techtoon Accounting\`).
2. **اضبط اتصال قاعدة البيانات** — راجع [INSTALLATION_GUIDE.md](INSTALLATION_GUIDE.md).
3. **شغّل البرنامج** — انقر مرتين على `Techtoon.UI.exe`، أو استخدم `run_techtoon.bat`.

> لا تُحذف أي ملف من مجلد `Application` — كل الملفات مطلوبة للتشغيل.

## 🔐 تفعيل البرنامج

### أين يتم التفعيل؟

**داخل البرنامج:** `الإعدادات` ← تبويب **`تفعيل البرنامج`** ← زر **`📄 استيراد ملف الترخيص`**

### خطوات التفعيل

1. افتح البرنامج وسجّل الدخول.
2. اذهب إلى **الإعدادات** (أسفل قائمة التنقل الجانبية).
3. اختر تبويب **«تفعيل البرنامج»**.
4. اضغط **«استيراد ملف الترخيص»** واختر الملف (`.key` / `.lic`).
5. تظهر رسالة تأكيد، وتظهر حالة الترخيص (النوع، الانتهاء، المدة المتبقية).

### قواعد مهمة

| القاعدة | التفصيل |
|---------|---------|
| **لا يوجد ربط بجهاز** | الترخيص يعمل على **أي كمبيوتر** — لا يُطلب معرّف جهاز |
| **التحقق قبل الحفظ** | يُفحص التوقيع الرقمي (HMAC-SHA256) وتاريخ الانتهاء **قبل** كتابة الملف |
| **لا يُستبدل ترخيص صالح** | استيراد ملف تالف أو منتهي **لا** يمسح ترخيصًا ساريًا |
| **الكتابة ذرّية** | يُكتب ملف مؤقت ثم يُستبدل — لا ملف ترخيص ناقص |
| **الفترة التجريبية** | 10 أيام تلقائيًا من أول تشغيل (لا يلزم ملف) |

### أين يُحفظ الترخيص؟

```
%APPDATA%\TechtoonAccounting\license.key
```

(يمكن أيضًا وضع `license.key` بجانب `Techtoon.UI.exe` في النسخة المحمولة.)

## 📄 أنواع التراخيص

| النوع | الملف | المدة |
|-------|-------|-------|
| تجريبي | `Licenses\License_Trial.key` | 10 أيام |
| شهري | `Licenses\License_Monthly.key` | شهر |
| سنوي | `Licenses\License_Yearly.key` | سنة |
| مدى الحياة | `Licenses\License_Lifetime.key` | غير محدودة |

> هذه الرخص نموذجية للاختبار — **أصدر رخصة حقيقية للعميل** عبر `Tools\Techtoon.LicenseTool.exe`.

## 🛠️ للمورد: إصدار رخصة لعميل

```powershell
# إصدار رخصة (تعمل على أي جهاز — بدون ربط)
.\Tools\Techtoon.LicenseTool.exe generate --type yearly --customer "شركة الأمل" --out "license.key"

# إصدار رخصة مرتبطة بجهاز معيّن (اختياري)
.\Tools\Techtoon.LicenseTool.exe machine-id
.\Tools\Techtoon.LicenseTool.exe generate --type lifetime --customer "شركة الأمل" --machine "313016CF4B7F5FEF" --out "license.key"

# التحقق من ملف ترخيص
.\Tools\Techtoon.LicenseTool.exe verify license.key

# عرض حالة الترخيص على هذا الجهاز
.\Tools\Techtoon.LicenseTool.exe status
```

| الأمر | الوظيفة |
|-------|---------|
| `generate --type <lifetime\|yearly\|monthly\|trial>` | إصدار رخصة موقّعة (تتحقق من نفسها قبل التسليم) |
| `--days N` | مدة مخصصة بالأيام (للتجريبي) |
| `--customer "اسم"` | اسم العميل/الشركة |
| `--machine <ID>` | ربط بجهاز (اختياري — اتركه فارغًا لغير المربوط) |
| `--out <file>` | مسار ملف الإخراج |
| `verify <file>` | التحقق من التوقيع والنوع والانتهاء |
| `status` | حالة ترخيص هذا الجهاز |
| `machine-id` | معرّف الجهاز (تشخيص فقط) |

## ❓ حل المشاكل

| المشكلة | الحل |
|---------|------|
| البرنامج لا يفتح | شغّل `Techtoon.UI.exe` من موجّه الأوامر لرؤية رسالة الخطأ، واقرأ `techtoon.log` |
| `license` غير صالح | الملف تالف أو معدَّل — أعد طلب الملف من المورد |
| «تعذّر الاتصال بقاعدة البيانات» | راجع `appsettings.json` / متغير البيئة `TECHTOON_PG_CONNECTION` |
| «لم يتم العثور على قاعدة البيانات» | أنشئ قاعدة البيانات أولًا (دليل التثبيت) |
| رسالة «البرنامج غير مفعّل» | استورد ملف الترخيص من `الإعدادات ← تفعيل البرنامج` |
| فشل `Techtoon.LicenseTool.exe` | تأكد أن `Tools\` يحتوي كل الملفات المرافقة |
