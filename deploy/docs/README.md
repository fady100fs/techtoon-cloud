# TECHTOON ACCOUNTING — دليل التوزيع والتشغيل

## 📦 محتويات الحزمة

```
deploy\distribution\

├── TechtoonSetup.exe         ← ملف التثبيت (ينشئ البرنامج على جهاز العميل)
├── run_techtoon.bat          ← تشغيل البرنامج (نقرة مزدوجة)
├── check_license.bat         ← عرض حالة الترخيص
├── issue_license.bat         ← إصدار رخصة لعميل (للمورد)
├── Application\              ← ملفات البرنامج (Techtoon.UI.exe — مستقل بالكامل)
├── Tools\
│   └── Techtoon.LicenseTool.exe   ← أداة الترخيص (للمورد)
├── Licenses\                 ← رخص موقّعة جاهزة (تجريبي / شهري / سنوي / مدى الحياة)
├── Documentation\            ← هذا الملف + دليل التثبيت + سكربت قاعدة البيانات
├── Logs\                     ← سجلات التشغيل (تُنشأ تلقائيًا)
├── Backups\                  ← النسخ الاحتياطية (تُنشأ تلقائيًا)
└── Manuals\                  ← أدلة المستخدم
```

## 📦 التثبيت على جهاز العميل (ملف EXE واحد)

ملف **`TechtoonSetup.exe`** (≈ 73 ميجابايت) يثبّت البرنامج على أي جهاز Windows
دون الحاجة إلى تثبيت .NET — البرنامج نفسه مستقل بالكامل.

| الخطوة | الإجراء |
|--------|---------|
| 1 | انسخ `TechtoonSetup.exe` إلى جهاز العميل |
| 2 | شغّله (يطلب صلاحية مدير — أو استخدم `/CURRENTUSER` للتثبيت بلا صلاحيات) |
| 3 | اختر اللغة (عربي / English) ومجلد التثبيت |
| 4 | اختياري: فعّل «اختصار على سطح المكتب» |
| 5 | بعد التثبيت شغّل البرنامج من قائمة ابدأ |

### خيارات سطر الأوامر

| الخيار | الوظيفة |
|--------|---------|
| `/CURRENTUSER` | تثبيت للمستخدم الحالي (بلا صلاحيات مدير) |
| `/DIR="C:\Path"` | مجلد التثبيت |
| `/VERYSILENT` | تثبيت صامت (بدون واجهة) |
| `/LOG=file.log` | كتابة سجل التثبيت |
| `/HELP` | عرض كل الخيارات |

> **الترخيص:** بعد التثبيت يظهر البرنامج في **وضع تجريبي (10 أيام)**.
> لتفعيله ضع ملف الترخيص `license.key` بجوار البرنامج، أو فعّله من
> **الإعدادات ← تفعيل البرنامج**. (راجع «🔐 تفعيل البرنامج» أدناه.)

### إلغاء التثبيت

من **إعدادات ويندوز ← التطبيقات** أو بتشغيل `unins000.exe` من مجلد التثبيت.

### إعادة بناء ملف التثبيت

```powershell
# يتطلب Inno Setup 6 مثبتًا: https://jrsoftware.org/isdl.php
powershell -ExecutionPolicy Bypass -File deploy\installer\build-installer.ps1
```

يُنتج: `dist\TechtoonSetup.exe`

## 🚀 التشغيل على أي جهاز Windows

### المتطلبات

| البند | المطلوب |
|-------|---------|
| نظام التشغيل | Windows 10 / 11 (64-bit) |
| معالج | Intel Core i3 أو أفضل |
| ذاكرة | 4 GB أو أكثر |
| مساحة | 250 MB للبرنامج + مساحة قاعدة البيانات |
| **.NET Runtime** | ❌ **غير مطلوب** — النسخة self-contained |
| قاعدة البيانات | PostgreSQL 12 أو أحدث |

### الخطوات

1. **انسخ مجلد `Application` كاملًا** إلى أي مكان على الجهاز
   (مثلًا `C:\Program Files\Techtoon Accounting\`).
2. **اضبط اتصال قاعدة البيانات** — راجع [INSTALLATION_GUIDE.md](INSTALLATION_GUIDE.md).
3. **شغّل البرنامج** — انقر مرتين على `Techtoon.UI.exe`، أو استخدم `run_techtoon.bat`.

> لا تُحذف أي ملف من مجلد `Application` — كل الملفات مطلوبة للتشغيل.

## 🔐 تفعيل البرنامج

### أين يتم التفعيل؟

**داخل البرنامج:** `الإعدادات` ← تبويب **`تفعيل البرنامج`** ← زر **`📄 استيراد ملف الترخيص`**

### خطوات التفعيل

1. افتح البرنامج وسجّل الدخول.
2. اذهب إلى **الإعدادات** (أسفل قائمة التنقل الجانبية).
3. اختر تبويب **«تفعيل البرنامج»**.
4. اضغط **«استيراد ملف الترخيص»** واختر الملف (`.key` / `.lic`).
5. تظهر رسالة تأكيد، وتظهر حالة الترخيص (النوع، الانتهاء، المدة المتبقية، اسم العميل).

### قواعد مهمة

| القاعدة | التفصيل |
|---------|---------|
| **لا يوجد ربط بجهاز** | الترخيص يعمل على **أي كمبيوتر** — لا يُطلب معرّف جهاز |
| **التحقق قبل الحفظ** | يُفحص التوقيع الرقمي (HMAC-SHA256) وتاريخ الانتهاء **قبل** كتابة الملف |
| **لا يُستبدل ترخيص صالح** | استيراد ملف تالف أو منتهي **لا** يمسح ترخيصًا ساريًا |
| **الكتابة ذرّية** | يُكتب ملف مؤقت ثم يُستبدل — لا ملف ترخيص ناقص |
| **الفترة التجريبية** | 10 أيام تلقائيًا من أول تشغيل (لا يلزم ملف) |
| **الترقية والتجديد** | استيراد رخصة جديدة (مثلاً سنوي بعد شهري) **يحدّث** الترخيص الحالي فورًا |

### أين يُحفظ الترخيص؟

يُبحث عن الترخيص في مكانين بالترتيب:

1. `%APPDATA%\TechtoonAccounting\license.key` ← المسار الرسمي (يكتبه البرنامج عند الاستيراد)
2. `license.key` بجانب `Techtoon.UI.exe` ← **للنسخة المحمولة** (انسخه مع البرنامج على USB)

> ضع `license.key` بجانب الـ EXE لتوزيع محمول يعمل على أي جهاز بلا تثبيت.

### ترقية العميل (تغيير الاشتراك)

| الخطوة | الإجراء |
|--------|---------|
| 1 | أصدر رخصة جديدة بنفس اسم العميل بالمدة المطلوبة |
| 2 | أرسل الملف الجديد للعميل |
| 3 | العميل: `الإعدادات ← تفعيل البرنامج ← استيراد ملف الترخيص` |
| 4 | تُستبدل الرخصة القديمة تلقائيًا ويظهر النوع الجديد (مثال: شهري ← سنوي) |

> بيانات العميل (فواتيره، أطرافه، مخزونه) **لا تتأثر** بتغيير الترخيص — الترخيص مستقل تمامًا عن البيانات.

## 🛠️ للمورد: إصدار رخصة لعميل

### الطريقة السريعة (نقرة مزدوجة)

```
issue_license.bat yearly "شركة الأمل للتجارة"
```

ينتج ملف `شركة الأمل للتجارة_license.key` جاهزًا للإرسال للعميل.

### الطريقة الكاملة (PowerShell / CMD)

```powershell
# إصدار رخصة (تعمل على أي جهاز — بدون ربط)
.\Tools\Techtoon.LicenseTool.exe generate --type yearly --customer "شركة الأمل للتجارة" --out "license.key"

# إصدار رخصة مرتبطة بجهاز معيّن (اختياري)
.\Tools\Techtoon.LicenseTool.exe machine-id
.\Tools\Techtoon.LicenseTool.exe generate --type lifetime --customer "شركة الأمل للتجارة" --machine "313016CF4B7F5FEF" --out "license.key"

# التحقق من ملف ترخيص قبل إرساله
.\Tools\Techtoon.LicenseTool.exe verify license.key

# التحقق من ترخيص مُثبَّت في مجلد توزيع
.\Tools\Techtoon.LicenseTool.exe status "C:\Techtoon\Application"

# عرض حالة الترخيص على هذا الجهاز
.\Tools\Techtoon.LicenseTool.exe status
```

| الأمر | الوظيفة |
|-------|---------|
| `generate --type <lifetime\|yearly\|monthly\|trial>` | إصدار رخصة موقّعة (تتحقق من نفسها قبل التسليم) |
| `--days N` | مدة مخصصة بالأيام (للتجريبي) |
| `--customer "اسم"` | اسم العميل/الشركة (يظهر في البرنامج) |
| `--machine <ID>` | ربط بجهاز (اختياري — اتركه فارغًا لغير المربوط) |
| `--out <file>` | مسار ملف الإخراج |
| `verify <file>` | التحقق من التوقيع والنوع والانتهاء |
| `status [dir\|file]` | حالة الترخيص (لمجلد توزيع أو ملف) |
| `machine-id` | معرّف الجهاز (تشخيص فقط) |

### قواعد إصدار التراخيص

| القاعدة | لماذا |
|---------|-------|
| **لا تربط بجهاز** إلا بطلب صريح من العميل | الترخيص غير المربوط يعمل على أي جهاز — يسهّل النقل والترقية |
| **اكتب اسم العميل** في `--customer` | يظهر في `الإعدادات ← تفعيل البرنامج` فيتأكد العميل أنه رخصته |
| **أرسل الملف فقط** — لا ترسل `machine-id` | لا حاجة لأي بيانات إضافية |
| **تحقّق قبل الإرسال** (`verify`) | يضمن أن الملف سليم وغير منتهي |
| **للترقية**: أصدر رخصة جديدة بنفس الاسم | تُستبدل القديمة تلقائيًا ولا تتأثر بيانات العميل |

## 📦 استيراد/تصدير البيانات (مجمّعات) — عبر ملفات Excel

البرنامج يوفّر صفحة **«🚞 الاستيراد / التصدير»** لنقل البيانات بين الأجهزة **بملفات Excel (.xlsx)**:

| المُجمّع | يغطّي |
|---------|-------|
| 👥 العملاء والموردون | الحسابات + الأطراف |
| 📦 الأصناف والمخزون | الأصناف + التصنيفات + الكيت + المخازن + الأرصدة |
| 🧾 فواتير البيع | الفواتير + سطورها + دفعاتها + الأطراف + الأصناف |
| 🛒 فواتير الشراء | نفس المجموعة لفواتير الشراء |
| 🔄 الاشتراكات | قوالب الفواتير المتكررة + خطوطها |
| 📊 حركات المخزون | المخازن + الأرصدة + كل الحركات |
| 💰 البيانات المالية | الخزائن + المصروفات + القيود + الحسابات |
| 🗄️ كل البيانات | نسخة كاملة |

### تنسيق ملف Excel

| العنصر | الوصف |
|--------|-------|
| **ورقة لكل جدول** | اسم الورقة = اسم الجدول (`accounts`, `parties`, `items` …) |
| **الصف الأول** | رؤوس الأعمدة (أسماء أعمدة الملف) |
| **الصفوف التالية** | البيانات |
| **ورقة `_bundle`** | بيانات وصفية: `bundle_id` و `title` و `schema_version` و `exported_at` |

### لماذا هو قابل للنقل بين الأجهزة

الملف يحتوي **مفاتيح طبيعية** بدل أرقام قاعدة البيانات:

| العمود في الملف | المعنى | بدل |
|----------------|--------|------|
| `account_code` | كود الحساب (`1000`) | `account_id` (`1`) |
| `item_barcode` | باركود الصنف (`ITM-001`) | `item_id` (`91`) |
| `party_name` | اسم الطرف | `party_id` |
| `warehouse_code` | كود المخزن | `warehouse_id` |

> لذلك يعمل نفس الملف على أي قاعدة بيانات — لا حاجة لإعادة ترقيم.

### كيف تستعمله

| الخطوة | الإجراء |
|--------|---------|
| 1 | **تصدير:** اختر المجمّع ← «تصدير المجمّع إلى ملف Excel» ← يُحفظ `.xlsx` |
| 2 | عدّل الملف في Excel إن أردت (أضف صفوفًا/صحّح بيانات) |
| 3 | **استيراد:** «اختيار ملف Excel» ← اختر الملف ← **معاينة** تظهر الأرقام قبل التنفيذ |
| 4 | اختر «تخطّي الموجود» (الافتراضي) أو «تحديث» ← «تنفيذ الاستيراد» |

### الضوابط

| الضابط | التفصيل |
|--------|---------|
| **ذرّي** | الاستيراد في معاملة واحدة — كله أو لا شيء |
| **معاينة أولًا** | تقرير لكل جدول (جديد / تحديث / متخطّى / أخطاء) **قبل** أي كتابة |
| **يتخطّى الموجود** | الافتراضي: لا يغيّر بيانات موجودة (آمن) |
| **ينشئ المراجع** | عميل/صنف/حساب غير موجود يُنشأ تلقائيًا (يمكن إيقافه) |
| **مفاتيح آمنة** | تطابق بـ `IS NOT DISTINCT FROM` — الصف الفارغ لا يتكرر |
| **بدون ترميز** | كل القيم نصية بصيغة ISO — لا تتأثر بإعدادات اللغة |

## 🔐 نظام الصلاحيات والأدوار

لكل مستخدم **دور واحد** يحدد ما يراه وما يستطيع فعله. تُدار الأدوار من داخل البرنامج:
**«⚙️ الإعدادات والإدارة» ← «🛡️ الأدوار والصلاحيات»**.

### كيف يعمل

| الطبقة | الوصف |
|--------|-------|
| **الصلاحية** | اسم بصيغة `module.action` (مثل `invoices.edit`) — 88 صلاحية موزّعة على 29 وحدة |
| **الدور** | مجموعة صلاحيات — 7 أدوار جاهزة + أدوار مخصصة تُنشئها بنفسك |
| **المستخدم** | له دور واحد (`users.role_id`) |
| **الاستثناء** | صلاحية فردية فوق دور المستخدم: **منح** يضيف، **منع** يسحب |

**ترتيب الحل:** استثناء المستخدم ← صلاحية الدور ← منع.

### الأدوار الجاهزة

| الدور | الوصف | عدد الصلاحيات |
|-------|-------|---------------|
| 🛡️ **مدير النظام** (ADMIN) | كل شيء — بما فيه المستخدمون والأدوار | 88 |
| 👔 **مدير** (MANAGER) | كل العمليات التشغيلية والتقارير — بلا إدارة المستخدمين ولا حذف بيانات العمل | 83 |
| 🧮 **محاسب** (ACCOUNTANT) | الفواتير والمدفوعات والمالية والقيود والتقارير والمخزون | 47 |
| 🛍️ **مندوب مبيعات** (SALESPERSON) | فواتير البيع والأطراف والعروض | 10 |
| 💵 **كاشير** (CASHIER) | التحصيل والفواتير وعرض الخزائن | 8 |
| 📦 **أمين مخزن** (STOREKEEPER) | الأصناف والمخازن والجرد والتسويات | 15 |
| 👁️ **مطّلع (عرض فقط)** (VIEWER) | عرض كل الصفحات دون أي تعديل | 27 |

### ماذا يتغيّر فعليًا لكل مستخدم؟

| | مدير النظام | كاشير |
|---|---|---|
| عدد أزرار القائمة الجانبية | **22** | **8** |
| لوحة التحكم | ✅ | ✅ |
| الفواتير والأطراف والمدفوعات | ✅ | ✅ |
| المخازن والتحويلات والجرد والتسويات | ✅ | ❌ |
| القيود والتقارير المالية | ✅ | ❌ |
| الإعدادات والمستخدمون والأدوار | ✅ | ❌ |
| الاستيراد/التصدير وإدارة البيانات | ✅ | ❌ |

- **الأزرار المخفية تختفي فعلًا** من القائمة الجانبية (وليست معطّلة).
- **والمحاولة للوصول المباشر** لصفحة غير مصرّح بها تُرفض برسالة واضحة.
- **والعمليات الحساسة** (إدارة المستخدمين، حذف بيانات العمل) محمية بصلاحية مستقلة.

### استخدام الأدوار

1. افتح **«🛡️ الأدوار والصلاحيات»**.
2. **تبويب «الأدوار»**: اختر دورًا ← مصفوفة الصلاحيات (منظّمة حسب الوحدة) ← «تحديد الكل / إلغاء الكل» ← **«حفظ صلاحيات الدور»**.
3. **زر «دور جديد»**: أنشئ دورًا مخصصًا (اسم إنجليزي + اسم عربي معروض).
4. **تبويب «المستخدمون»**: اختر المستخدم ← اختر دوره من القائمة ← ثم **استثناءاته** (تورث من الدور / منح / منع) ← **«حفظ الاستثناءات»**.

> ملاحظة: زر «صلاحيات» في شاشة «إدارة المستخدمين» يفتح نفس النافذة (استثناءات المستخدم فقط).

### إضافة مستخدم

**«⚙️ الإعدادات والإدارة» ← «👥 إدارة المستخدمين» ← «+ مستخدم»** ← اختر **الدور** ← احفظ.
يُطلب من المستخدم تغيير كلمة المرور عند أول دخول.

## ❓ حل المشاكل

| المشكلة | الحل |
|---------|------|
| البرنامج لا يفتح | شغّل `Techtoon.UI.exe` من موجّه الأوامر لرؤية رسالة الخطأ، واقرأ `techtoon.log` |
| `license` غير صالح | الملف تالف أو معدَّل — أعد طلب الملف من المورد |
| «تعذّر الاتصال بقاعدة البيانات» | راجع `appsettings.json` / متغير البيئة `TECHTOON_PG_CONNECTION` |
| «لم يتم العثور على قاعدة البيانات» | أنشئ قاعدة البيانات أولًا (دليل التثبيت) |
| رسالة «البرنامج غير مفعّل» | استورد ملف الترخيص من `الإعدادات ← تفعيل البرنامج` |
| فشل `Techtoon.LicenseTool.exe` | تأكد أن `Tools\` يحتوي كل الملفات المرافقة |
| نسيان كلمة مرور المدير | `TECHTOON_BOOTSTRAP_ADMIN_PASSWORD` (12 حرفًا على الأقل) ثم أعد التشغيل |
