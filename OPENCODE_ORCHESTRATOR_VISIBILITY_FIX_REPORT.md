The `techtoon-orchestrator` agent (mode: primary) was not appearing in the OpenCode agent list, so the user could not select it.

## 2. Diagnosis

### 2.1 Root Cause

**OpenCode 1.2.0-beta.12 does NOT auto-select a primary agent.** The `default_agent` config option exists in the schema but there was **no `opencode.json` config file** in the project, so no default agent was set.

Additionally, the config file must be placed in `.opencode/` directory (project root), not in the project root directory. The app scans `.opencode/` directories for `opencode.json`/`opencode.jsonc` files.
