## 1. Failure Handling Design

### 1.1 Failure Types

| Failure Type | Description | Handling |
|-------------|-------------|----------|
| Agent not found | Agent name doesn't match any file | Report error, try alternative |
| Agent timeout | Agent takes too long to respond | Retry up to 3 times, then BLOCKED |
| Agent error | Agent returns error response | Log error, retry, then BLOCKED |
| Incomplete result | Agent returns partial result | Request clarification, retry |
| Conflict | Agents disagree | Present both views, request resolution |
| Permission denied | Agent lacks required permission | Report BLOCKED, suggest alternative |
| Depth exceeded | Subagent tries to invoke another subagent | Reject, report error |

### 1.2 Retry Strategy

```
Attempt 1: Invoke agent
  ↓ (if fails)
Attempt 2: Retry with simplified prompt
  ↓ (if fails)
Attempt 3: Retry with minimal context
  ↓ (if fails)
Mark as BLOCKED, report to user
```

### 1.3 Conflict Resolution

```
1. Collect results from all agents
2. Compare findings
3. If conflicts detected:
   a. Present both views
   b. Identify the disagreement
   c. Request resolution (user or higher-priority agent)
4. If no conflicts: proceed
```

### 1.5 Depth Limit Enforcement

- **Max depth**: 3 levels (Orchestrator → Specialist → Sub-specialist)
- Subagents cannot invoke other subagents (no `subagent` tool available)
- OpenCode enforces this at the tool level
- Verified: Attempting to invoke subagent from within a subagent context → not available

### 1.6 Error Recovery

```
1. Log the error (agent name, error message, timestamp)
2. Retry up to 3 times with increasing delay
3. If retry succeeds: continue
4. If retry fails: mark as BLOCKED
5. Report to user with error details
6. Suggest alternative approaches
```

### 1.7 Audit Trail

All delegation events are logged:
- Agent invoked (name, timestamp, task)
- Agent completed (name, timestamp, result)
- Agent failed (name, timestamp, error)
- Retry attempted (name, attempt number)
- Conflict detected (agents, disagreement)
- Resolution (method, decision)
