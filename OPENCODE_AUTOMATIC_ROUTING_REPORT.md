## 1. Automatic Routing Analysis

### 1.1 Can OpenCode Automatically Route to a Default Primary Agent?

**Answer: NO (in OpenCode 1.2.0-beta.12)**

- There is no `opencode.json` or `opencode.jsonc` configuration file in the project
- There is no `defaultAgent` or `primaryAgent` setting in the global `service.json`
- Primary agents (`mode: primary`) must be **manually selected** by the user from the OpenCode UI dropdown
- The `subagent` tool can only invoke `mode: subagent` agents, not `mode: primary` agents

### 1.2 What IS Supported

- Project-level agents in `.opencode/agents/` are auto-discovered
- Primary agents appear in the agent dropdown in the UI
- Subagents can be invoked by primary agents via the `subagent` tool
- The orchestrator can invoke all 11 specialist subagents

### 1.3 Routing Flow (Manual Selection Required)

```
User opens OpenCode → Selects "Techtoon Orchestrator" from dropdown → Sends task
  ↓
Orchestrator analyzes task → Identifies needed specialists → Invokes via subagent tool
  ↓
Specialists execute → Return results → Orchestrator collects → Reviews → Reports
```

### 1.4 Limitation

The user must manually select "Techtoon Orchestrator" as the primary agent before sending a task. There is no way to set it as the default agent automatically in this OpenCode version.

### 1.5 Mitigation

1. **User Guide**: `OPENCODE_AGENT_USER_GUIDE.md` provides step-by-step instructions
2. **Agent Description**: The orchestrator's description clearly states it's the primary entry point
3. **Global Agents**: The existing global agents are still available if the user doesn't select the orchestrator

### 1.6 Alternative: Use Global Agent

If the user prefers, they can copy `techtoon-orchestrator.md` to `~/.config/opencode/agents/` to make it available globally. However, it would still need to be manually selected.
